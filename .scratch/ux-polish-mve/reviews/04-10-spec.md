# Spec review — tickets 04–10

Range: `d4c0007...HEAD`. Focus: user-visible behaviour vs acceptance criteria.

## (a) Missing or partial

1. **Table wrapper / rounded clipping** — Spec Implementation Decisions: “table wrapper radius/header/hover”; story 29: “tables with rounded clipping”. Diff styles `table` itself (`border-radius` + `overflow: auto` + `border-collapse: collapse`) with no wrapper. Corner clipping of cell borders remains unreliable.

2. **Smoke alert coverage** — Ticket 10: sample must cover “alerts…”. `test/markdown/UxPolish.md` only exercises `[!NOTE]` and `[!WARNING]`; TIP / CAUTION / IMPORTANT are unchecked in the fixture.

3. **Figcaption “when warrants”** — Ticket 08 / story 31: “figcaption when alt/title warrants it”. `getImageCaption` treats any non-empty `alt`/`title` as warranting a caption (no “useful vs decorative” filter).

## (b) Scope creep

1. **Always wrap images in `<figure>`** — Story 31 asks radius/border/shadow and figcaption when appropriate. `enhanceImagePresentation` wraps every non-linked image in a generated `<figure>` even when there is no caption.

2. **Chips hide multi-value tails** — Ticket 06 / story 20 ask compact chips for short metadata, not data suppression. `.vditor-front-matter--chips .vditor-properties__row--chip .vditor-properties__list li:not(:first-child) { display: none; }` drops all but the first list item (e.g. tags).

## (c) Looks implemented but wrong

1. **Figure-in-paragraph editing risk** — Ticket 08: “editing/insert paths still work”. Injecting `<figure>` around images that Lute places inside `<p>` yields invalid HTML; browsers may split the paragraph, so chrome can land while WYSIWYG structure regresses.

2. **Table polish vs wrapper contract** — Header emphasis and row hover land, but the Spec’s “wrapper” clipping contract is not met; radius on a collapsed `table` can look finished while corners stay square.

3. **Chips look compact but omit values** — Codicon key icons and pill layout satisfy “uses Codicon”, yet hidden list siblings mean chips mode does not faithfully present short multi-value frontmatter the user authored.

Alerts (04), code labels/copy (05), frontmatter setting default `table` (06), Actionable Empty State for PlantUML/Mermaid/image + retained host Open Settings (07), link/inline-code/hr + galleryBanner/category (09), and docs/smoke pack without version bump (10) largely match their tickets/ADRs 0003–0005. No Callout toolbar/Welcome/second preview found in this range.
