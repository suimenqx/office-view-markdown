# Async diagram and image renders are generation-guarded

PlantUML, Mermaid, and image loads commit to the Reading Surface only when `(stable block identity, source revision, renderer/theme config)` is still current and the host element is connected. Stale async results after edit, undo, delete, replace, or theme refresh must not write SVG/img/error chrome. Retry rereads current source rather than a closed-over snapshot. Loading / ready / error states are mutually exclusive and disposable; they do not invent undo history (ADR 0009) or steal focus anchors (ADR 0010). Keep ADRs 0001–0003: no default public PlantUML server, no silent probing, failures stay Actionable Empty State. Acceptance on `markdownViewer` only. Explicitly out of this wave: FindBar/inline-object reopen, Welcome/second preview/LLM.
