# Link-like and HTML objects share one activation contract

Ordinary links, link references, wiki links, images, and raw HTML islands expose one inline-object interaction contract on `office-view-markdown.markdownViewer`: stable source target (display vs destination), deterministic click/modifier/edit affordances, and a focus anchor that survives save/remove/re-render via ADR 0010. Edits commit through ADR 0009 (one intent → one undo/dirty). Raw HTML may stay a source popover, but save is one semantic transaction that preserves enclosing document position. Host opens (e.g. `wiki:`) use the same target object rather than a parallel click grammar. Explicitly out of this wave: FindBar reopen, Welcome/second preview/LLM, full arbitrary-DOM HTML authoring, and async diagram generation guards (next backlog item).
