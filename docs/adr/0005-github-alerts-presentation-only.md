# GitHub Alerts are presentation-only

Blockquotes marked with GitHub-style alert markers (`[!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!CAUTION]`, `[!IMPORTANT]`, and agreed variants) receive semantic styling via classes. The Markdown source is not rewritten on edit round-trip, and the product does not introduce a separate Callout block type or toolbar inserter in this effort.
