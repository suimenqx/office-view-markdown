# Opening a document must be visually stable

When a Markdown file opens into `office-view-markdown.markdownViewer`, the first paint of the Reading Surface must not flash an intermediate layout, jump Editor Font Size, or lose the last meaningful scroll/caret anchor for that document. Restore uses one persisted focus/scroll contract (same family as `cacheFocus` / document state): scroll position and caret/selection are applied after content is ready, not against a half-mounted chrome. Font size follows the configured Editor Font Size from the first applied stylesheet—no default→override flicker. Acceptance runs only on the custom editor viewType (stock Markdown does not count). Explicitly out of this wave: in-session caret continuity across DOM/CodeMirror boundaries and semantic undo transactions (later waves).
