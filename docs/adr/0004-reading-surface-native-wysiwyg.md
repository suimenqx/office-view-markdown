# Reading Surface polish stays inside the WYSIWYG editor

Professional reading aesthetics (Design Tokens, Editor Font Size, outline chrome, GitHub Alerts, content-block polish) are applied to the existing custom editor Reading Surface. The product does not add a separate preview pane, auto-open side preview, full-page Welcome screen, remote/bundled web fonts, or LLM/API-key surfaces. Typography follows the VS Code editor font family; measure and type size are adjustable without turning Office View Markdown into a preview-only reader.
