# Find/replace is a document-semantic operation

Find, Find Next, Replace, and Replace All operate over the canonical authored document stream—not a mix of DOM text walks and separate CodeMirror scans that disagree on count and undo. Matches share one source-range identity (prose, inline markup, and embedded code/math blocks); crossing emphasis/link boundaries must not drop a hit; mounting a block to show a match must not change the result set. Replace Current / Replace All commit through ADR 0009’s transaction boundary (one intent → one undo unit) and restore position via ADR 0010’s document position. Presentation chrome, hidden, and aria-hidden nodes stay out of the searchable stream by policy, not ad-hoc skip lists alone. Acceptance on `markdownViewer` only. Explicitly out of this wave: FindBar skin redesign, Welcome/second preview/LLM, reopening caret or open-doc waves.
